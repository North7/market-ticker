# Market Ticker

給副螢幕（13 吋 MacBook）長時間掛著的行情看板，可以隨時切換視覺主題。

## 使用

雙擊 `start.command` 啟動（本機伺服器＋防休眠＋Chrome 全螢幕），雙擊 `stop.command` 停止。
只需要 macOS 內建的 `python3`；網頁需要連網（行情、字型）。

### 線上版（GitHub Pages）

<https://north7.github.io/market-ticker/> 不用安裝，但沒有本機伺服器，所以拿不到台美股，
六張小卡改成加密指標（純前端直連各交易所公開 API）：

| 卡片 | 內容 | 來源 |
|---|---|---|
| 鯨魚買賣 | 近 1 小時 ≥ 10 萬美元大單的淨買賣額 | Binance 現貨＋合約逐筆 |
| 爆倉 | 開頁以來多空爆倉金額（無免費歷史，從開頁開始累積） | Binance＋Bybit 爆倉推播 |
| 主動買賣比 | 合約主動買量 ÷ 主動賣量（5 分） | Binance Futures |
| Coinbase 溢價 | Coinbase BTC-USD 減 Binance BTCUSDT，正值代表美國買盤強 | Coinbase |
| 恐懼貪婪 | 0–100 情緒指數與昨日、7 日前比較 | alternative.me |
| 200 日線乖離 | 現價相對 200 日均線的百分比，小字附 4H RSI(14) | Binance 日 K／4H K |

標題小字另外顯示 ETH 價格和穩定幣總供給（DefiLlama）。

每次推上 main 會自動部署並蓋上版本號，例如 `v12 · 10/16 23:05`（版本＝commit 數，時間為台北部署時間）。
版本號只顯示在底部主題選單最右邊（移動滑鼠或點一下畫面叫出），本機執行顯示 `local`；也可以直接開 `version.json` 查看。
開著的網頁每 5 分鐘、或切回分頁時會檢查新版，有新版就自動重新載入並提示「已更新」，不必手動清快取。
本機版也可以加 `?mode=crypto` 強制看加密指標，`?mode=stocks` 則強制股票模式。

## 操作

| 鍵 | 作用 |
|---|---|
| 1–8、← → | 切換主題（會記住上次的選擇） |
| A | 自動輪播，每 10 分鐘換一個 |
| F、雙擊或「全螢幕」按鈕 | 全螢幕（右上角和底部選單都有按鈕） |
| 移動滑鼠 | 顯示底部主題選單，2.5 秒後自動隱藏 |

### 手機與平板

八個主題都支援手機、iPad（直放和橫放）和大螢幕，直放時會自動改成上下排版。

| 手勢 | 作用 |
|---|---|
| 左右快速一揮 | 切換主題 |
| 點一下 | 叫出底部主題選單，再點一下立即收起 |
| 按住或慢慢拖圖表 | 查看該點的時間與開高低收 |
| 點指標卡 | 打開詳情（說明＋可查的歷史圖） |

iPhone 的 Safari 不支援網頁全螢幕，可以在分享選單選「加入主畫面」，之後從主畫面打開就是全螢幕。

所有主題總覽（即時縮圖）：`http://127.0.0.1:8686/themes/`。
舊的 HUD 版本還在 `classic.html`，舊方案在 `themes/archive/`。

## 資料來源

- BTC：Binance WebSocket（逐筆、1m、4h、24h ticker），斷線自動重連並補齊
- 台股：證交所 MIS 約 5 秒更新，Yahoo 補當日 5 分 K
- 美股：Yahoo，盤中約 10 秒更新

## 長時間顯示

伺服器以 `caffeinate -d` 執行、網頁要求 Wake Lock；每 3 分鐘整體微移幾個像素防烙印。
開機自動啟動：系統設定 → 一般 → 登入項目，加入 `start.command`。
